# Improved Detection of Fraud Cases

## Project Overview
This project focuses on improving fraud detection for both e-commerce and bank transactions using machine learning.  
It is developed as part of **B8W5 – Fraud Detection Challenge**.

## Datasets
- Fraud_Data.csv (E-commerce transactions)
- IpAddress_to_Country.csv (IP to country mapping)
- creditcard.csv (Bank transactions)
